§06

Transactions & Double-Spend

Syllabus link → Unit 2/3: Bitcoin transactions + Concept of Double Spending — Transactions transfer balance between wallets. The double-spend problem: attempting to spend the same funds twice. The network confirms the first, rejects the second — demonstrating why confirmation prevents double-spending.

⚠ Attempt Double-Spend

This fires two transactions simultaneously using a wallet’s entire balance to two different recipients. The first transaction confirms and reduces the balance to zero; the second is rejected (insufficient funds). This demonstrates why network confirmation, not the transaction message itself, is what prevents double-spending.
